1. **登录响应字段是 `access_token`**（在 `data` 内），不是 `token`。原方案 Step2 脚本 grep `"token":"..."` 取空 → 下游 `UNAUTHORIZED`。已改为 `grep '"access_token":"[^"]*"'`。

### 7.5 复盘（下不为例）
- PowerShell 远端调用**禁用 `$host` 变量名**——它是 PS 保留的 host 接口对象，赋值后 `ssh` 会拿 `system.management.automation.internal.host.internalhost` 当主机名静默失败。本次因此浪费一轮，后续改用 `$rhost`。
- 取回远端产物统一走 `ssh ... 'cat /tmp/x' | Set-Content -Encoding UTF8 <本地>`；容器内读用 `docker exec <c> sh -c 'cat ...'`（git-bash shim 缺 cat/head，但容器内 cat 正常）。
- 写脚本进容器用 `docker cp`（规避 sh 单/双引号转义地狱）；远端 bash 用 `Get-Content -Raw <lf> | ssh ... 'bash -s'`，LF 由 PS `.NET` 写入器转。
