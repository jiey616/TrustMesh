# 中心化调度会议架构 — 实施计划

## 架构图

```
                                  主持人（PM Agent）
                                  │
        ┌───────────┬──────────┬──┴──┬──────────┬──────────┐
        │           │          │     │          │          │
     数据Agent   执行Agent   复盘Agent 风控Agent 文档Agent  研发Agent
```

## 会议全流程

```
1. 创建会议（用户）
   ├─ 定义会议目标
   ├─ 拆分为议题项，每项指定执行 Agent + 权重
   └─ 设置时间约束、输出要求

2. 会前准备（主持人自动触发）
   ├─ 向各执行 Agent 分发议题 → 要求预加载数据
   ├─ 各 Agent 回复准备就绪 + 预览观点
   └─ 所有 Agent 就绪后通知用户"可以开始了"

3. 会议讨论（主持人轮询，前端 round-robin 展示）
   ├─ 按权重从高到低轮询发言
   ├─ 每轮：Agent A 输出结论 → 主持人点评 → Agent B 输出结论 → ...
   ├─ 冲突由主持人拦截/调解
   └─ 用户可随时插话

4. 会议结束（主持人自动生成）
   ├─ 汇总纪要（markdown）
   ├─ 生成待办事项，绑定责任人（Agent ID）
   ├─ 上传纪要文件到项目文件夹
   └─ 用户可在会后从待办创建任务
```
