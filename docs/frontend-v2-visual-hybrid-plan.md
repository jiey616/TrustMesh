# frontend-v2 视觉混合改造方案

> 吸收 Quiet Signal 的**排版纪律与治理机制**，保留 TrustMesh 的**深色画布与紫色品牌信号**。  
> 状态：**待确认，未实施**。本文件只做方案，未改动任何前端代码。

## 0. 一句话结论

不换画布、不换品牌色，只做三件事：**结构直角化、表面填充收敛、建立 Token 层**。  
影响面可控（样式值替换为主，无逻辑改动），气质提升明显，且与 AI Office 3D 的独立视觉体系不冲突。

## 1. 为什么不是"整体换成 Quiet Signal"

Quiet Signal 是**近白**体系，与现网**根本对立**，不是微调：

| 维度 | Quiet Signal               | TrustMesh 现网                   |
| -- | -------------------------- | ------------------------------ |
| 画布 | 近白 `#FAFAFA` + 黑 `#0A0A0A` | 深色 `#0a0a12`                   |
| 质感 | **明令禁止**玻璃拟态、紫色渐变、装饰性 3D   | Aceternity + Neon Glass        |
| 圆角 | 结构 **0**，控件 4px            | 卡片 16px                        |
| 卡片 | 禁止"每段一个卡片的卡片墙"             | 卡片 `rgba(255,255,255,0.03)` 体系 |

整体替换 = 深色霓虹玻璃推倒重来，工作量大且会与 AI Office 3D 打架。

**唯一共识**：紫色都只作信号（彼 `#7C3AED` vs 此 `#6d5ff5`，几乎同色）。这条是我们能安全吸收的地基。

## 3. 改造项

### 明确保留（不动）

- 深色画布 `#0a0a12`
- 紫色 CTA `#6d5ff5`
- 圆形头像 `borderRadius: 50`、胶囊标签 `999`（这两类有明确语义）
- **AI Office 3D 页面**（`OfficePage` 及 `components/office/*`）——独立视觉体系，本次完全不涉及

### P0 — 圆角收敛（结构直角化）

Quiet Signal 核心规则：`geometry.radius.structure = 0`，`geometry.radius.small = 4px`，且**禁止外层容器、内层表面、控件同时圆角化**。

| 层级                | 现在                | 改为      | 说明                 |
| ----------------- | ----------------- | ------- | ------------------ |
| 页面 / 布局外壳         | 16 / 14 / 24 / 20 | **`0`** | 大结构保持硬朗，与横线相接处必须直角 |
| 次级内容区（面板、Section） | 12                | **`4`** | 确有独立边界的下层表面        |
| 控件（按钮、输入框、小卡）     | 8 / 10 / 6 / 9    | **`4`** | 统一                 |
| 头像 / 标签           | 50 / 999          | **不动**  | 有独立语义              |

净效果：12 种圆角 → **4 种**（`0` / `4` / `50` / `999`）。

### P1 — 表面填充收敛

7 种半透明 → **2 种**，建立真实层级：

| Token                  | 值                        | 用途                              | 吸收来源              |
| ---------------------- | ------------------------ | ------------------------------- | ----------------- |
| `surface`              | `rgba(255,255,255,0.04)` | 确有独立边界的表面                       | 0.03/0.04/0.05 合并 |
| `surface.sunken`       | `rgba(255,255,255,0.02)` | 次级、内收、不可编辑区                     | 0.02 保留           |
| ~~0.06 / 0.07 / 0.08~~ | —                        | **取消**，改由 `line` 或 `surface` 表达 | 原用于"更亮"的随意加深      |

`0.08` 的 46 处需要逐个判断：若承担 hover / 选中态 → 改用**边框 + 紫色信号**表达，而不是继续加深填充。

### P1 — 玻璃拟态收缩到"真浮层"

原则：**默认无玻璃**。只在存在真实抬升、浮层或遮挡关系时保留。

| 保留                             | 移除                                           |
| ------------------------------ | -------------------------------------------- |
| Drawer、Modal、Tooltip、下拉菜单、浮层卡片 | `MainLayout.tsx` 外壳、各页面主内容区、`index.css` 全局底噪 |

`GlowCard.tsx` 需单独决策：它是组件化的玻璃卡片，被多处复用。建议**保留但降级**——去掉 `backdropFilter`，只留边框 + 微弱填充（它本质是"卡片"不是"浮层"）。

### P2 — 紫色审计

48 处 `#6d5ff5` 逐项判断，规则：

- ✅ 保留：主 CTA、当前选中、焦点环、关键状态变化、关键数据强调
- ❌ 移除：大面积背景、长篇正文、纯装饰、与状态无关的常规标签

目标：**一个视图内只有一个主要紫色焦点**。

### P2 — 建立 Token 层（治理的地基）

新建 `src/theme/tokens.ts`，把散落值收敛为具名常量：

```ts
export const canvas    = '#0a0a12'
export const surface   = 'rgba(255,255,255,0.04)'
export const sunken    = 'rgba(255,255,255,0.02)'
export const line      = 'rgba(255,255,255,0.07)'
export const signal    = '#6d5ff5'
export const radius    = { structure: 0, small: 4, pill: 999, avatar: 50 } as const
```

这一步是"治理"的核心：**一处改，全局生效**；也才谈得上后面写禁止项。

### P2 — 写禁止项清单

落到 `docs/frontend-visual-rules.md`（或 `AGENTS.md` 附录），明确：

- 禁止层层圆角（外层/内层/控件同时圆角化）
- 禁止圆角 + 阴影 + 浅填充同时用于每个信息块
- 禁止用等宽等高卡片填补空画布
- 禁止紫色作大面积气氛场
- 禁止无真实状态的假仪表盘

## 4. 实施节奏（分阶段验证）

| 阶段 | 内容                               | 依赖   | 风险                     |
| -- | -------------------------------- | ---- | ---------------------- |
| 0  | 建 `theme/tokens.ts`（只加文件，不改现有样式） | 无    | 零                      |
| 1  | 圆角收敛 12 → 4 种                    | 阶段 0 | 低（纯样式值替换）              |
| 2  | 填充收敛 7 → 2 种 + 玻璃拟态收缩            | 阶段 1 | 中（需逐个判断 0.08 的 46 处语义） |
| 3  | 紫色审计 48 处                        | 阶段 2 | 中（需人眼确认焦点层级）           |
| 4  | 写禁止项清单                           | 阶段 3 | 零                      |

建议 **0+1 一批、2 一批、3+4 一批**，每批验证后再推下一项。

## 5. 验证方法（沿用项目既有铁律）

```bash
npx tsc -p tsconfig.app.json --noEmit      # 必须用这个 tsconfig，不能用默认
npx eslint src/...
docker-compose build frontend-v2           # 严禁手工 docker build -t 打 tag
docker-compose up -d --force-recreate frontend-v2
```

**bundle 指纹校验不能用组件名**（生产构建会 mangle），要用样式特征值，例如校验 `rgba(255,255,255,0.03)` 归零、`borderRadius: 4` 出现次数上升。

最后按 **Ctrl+Shift+R** 硬刷新 5174 目视确认。
