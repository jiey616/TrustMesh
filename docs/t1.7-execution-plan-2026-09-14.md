## 2. 决策：A 先部署 main 再验收 / B 现网如实验收

| | A. 先部署当前 main 再验收 | **B. 现网如实验收（推荐）** |

### 7 步（端点映射，细节见业务验收脚本）
1. **代建账号（替代路径）**：`POST /api/v1/auth/register` → 验 U2 可登录 + 个人 org 落 `organizations` + `org_memberships(role=owner)`。
2. **邀请（替代路径）**：U2 对自建 Org2 `POST /api/v1/organizations/:id/members {email:U2邮箱}` → 验成员关系。
3. **审批入企（agent）**：需一个**空闲 agent 节点**对 Org2 发起 join → `POST /api/v1/agents/join-requests/:id/approve`；非 owner 调 → 403。⚠️ **G7 前置**：当前 5 个已批准 agent 全属画宗，需确认是否有可新建/空闲节点；若无，本条转「读已有 join_requests 历史 + 新建 Org2 节点审批演示」或暂挂。
4. **跨成员共享 agent**：Org2 内建 agent → `OrgID=Org2`，同 org 成员可见可指派。
5. **建项目/会议/任务**：`POST /projects`、`POST /projects/:pid/meetings`、`POST /projects/:pid/tasks` → 归属 `org_id=Org2`。
6. **切企业 + 隔离**：前端租户切换器切 Org2（每请求带 `X-Org-Id: Org2`）；见隔离 canary。
7. **配额展示**：`GET /organizations/:id` → 前端配额区与接口一致（**仅展示、无强制**，G4）。
